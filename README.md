# ECOBuild
プロジェクト管理ツール

## GUI

```
ecobuild-gui            # Edge のアプリの窓（なければ既定のブラウザ）で開く
ecobuild-gui --no-browser --port 8765
```

- 手元だけで動くGUI（`src/ecobuild_gui/`）。操作はすべて `ecobuild -C <場所> <コマンド> --json` を実行して行う。
- GUIが自分で行うのは、CLIにない手元の処理だけ：モジュールの一覧と専用のcloneの登録（ツールの管理ディレクトリの `gui.json`）、エクスプローラーのファイルの一覧、フォルダ・空のファイルの作成、既定のアプリで開く、フォルダの選択。
- 画面：ハブ（モジュールの一覧・追加、既定の所有者、環境チェック・準備）と、モジュールごとの窓（モジュール：Project・依存・ブランチ・ビルド設定／作業空間：エクスプローラー・コミット・PR・ビルド／タスク管理：一覧・ボード・日程）。
