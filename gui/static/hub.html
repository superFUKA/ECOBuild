      環境の準備

      Git が GitHub CLI の認証を使うようにし、コミットの作成者（名前・メールアドレス）を設定します。

      AI のログイン（コンテナ用）

      コンテナの中の AI に渡すトークン。あれば、コンテナの中でログインせずに使えます。

      読み込んでいます…

      トークンの作り方

      「トークンを作る」で開く窓（claude setup-token）でブラウザーから許可すると、出たトークンを自動で保存します。拾えなかったときは、その窓か上の欄に貼ってください。サブスクリプションのアカウントで作れ、1年使えます。トークンがなければ、最初の1回だけコンテナの中でログインします。

      エージェントの窓

      アイコン・話し方（オペレーター・作業用）、オペレーターのモデル、返答の知らせ方、リングは、エージェントの窓の ⚙ で設定します。

      コンテナのイメージ

      作業空間をコンテナにしたときの元。型（cpp・generic 等）ごとに1つで、ECOBuild を更新すると作り直します（前の版は自動で片付けます）。
