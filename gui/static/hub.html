      環境の準備

      gitが GitHub CLI の認証を使うようにし、コミットの作者情報を設定します。

      このGUI

      GUIは裏で動いています。窓をすべて閉じると、しばらくして自動で終わります。すぐに終わらせるときは「GUIを終了」を押します。

      ECOBuild / モジュール

      モジュールを追加

      新しく作るか、GitHubにあるモジュールを取得するか、手元にあるモジュールを一覧に登録します。

      追加方法

      詳細設定 説明・所有者・公開範囲

      既定は非公開です。GitHubリポジトリの作成と初回Pushも行います。

      ECOBuildで作られたモジュールを取得し、依存先と生成ファイルを用意します。

      このフォルダの下にモジュール名のフォルダを作ります（親フォルダがなければ作ります）。
