      環境の準備

      Git が GitHub CLI の認証を使うように設定し、コミットの作成者（名前・メールアドレス）を設定します。

      このGUI

      GUIはバックグラウンドで動いています。ウィンドウをすべて閉じると、しばらくして自動で終了します。すぐに終了するには「GUIを終了」を押してください。

      モジュールを追加

      追加方法

      ECOBuildで作成したモジュールをcloneし、依存先と生成ファイルを用意します。

      このフォルダの下にモジュール名のフォルダを作ります。

      詳細設定 説明・所有者・公開範囲
